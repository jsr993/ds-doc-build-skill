# Locale: en

Strings the skill writes into the documentation and the report, English build. The skill reads **exactly one** locale file per build — the one matching the chosen documentation language.

## formats

| Key | Value |
|---|---|
| `date` | numeric `dd.mm.yy`, leading zeros required (`01`, not `1`), two-digit year. The format is dictated by the `ds-doc/changelog/log/date` component (three text slots joined with dots), so it is identical in every locale |
| `quotes` | `“…”` |
| `dash` | `—` without surrounding spaces |

## glossary

Property name → block `Title`. Properties not listed here keep their name verbatim.

| Property | Title |
|---|---|
| `Configuration` | Configurations |
| `Style` | Styles |
| `Size` | Sizes |
| `State` | States |

## write

The only strings the skill is allowed to write without them coming from the component. Placeholders in `<...>`.

| Key | Value |
|---|---|
| `anatomy.title` | Anatomy |
| `anatomy.description` | Use DevMode (Shift+D) to explore the component structure |
| `lead` (when component `description` is empty) | `<Name> — a component with <N> variants across the <axes, comma-separated> axes.` |
| `property-block.description` | `The \`<Name>\` property defines the <block title, lowercase>: <values, comma-separated>.` |
| `changelog.first-entry` | `First version of the component. Axes: <axis list>.` |
| `state-row` | value name verbatim; no explanation appended |
